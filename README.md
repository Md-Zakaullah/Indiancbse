# Northstar Academy — CBSE School OS demo

A modern, responsive school and hostel management demo built with plain HTML, CSS and JavaScript. No build step or external backend is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. Vercel can deploy this repository as a static site; leave the build command empty and use the repository root as the output directory.

## Demo modules

- Dashboard and school-day overview
- Student directory with search and add/edit/delete
- Daily attendance register
- CBSE-style exam results and grades
- Fees ledger using Indian rupees (INR)
- Hostel residents, wings and room allocation
- Staff directory and school notices
- JSON backup export and restore

## Data note

Demo data is stored in the browser's `localStorage` on the current device and browser. It is not shared or synced across users and is not suitable for real student records. Clearing browser data removes the demo data. Connect a secure backend/database and authentication before using this for a real school.
